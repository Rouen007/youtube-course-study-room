# YouTube 课程体系化研学五阶段方法论 (`S1–S5`)

> **Created by Xiao Ang** · YouTube 课程体系化研学与学习室脚手架核心方法论

---

## 阶段一 · 采集与结构化 (Ingest & Structure)

1. **输入与发现**：
   - 获取 YouTube 播放列表或系列视频 URL，确定分集列表；
   - 如有 B 站镜像（如中配版），记录对应分 P 规则，以便实现后续双端直达。
2. **字幕抽取与切片**：
   - 优先抽取官方或自动英文字幕（WebVTT / JSON3 格式）；
   - 清洗时间戳与无意义语气词，按照自然段落或分钟间隔进行切片（Chunking）；
   - 输出统一命名格式：`transcripts/{ep:02d}_{videoId}_{title}.md`。
3. **元数据构建**：
   - 提取每集时长、标题、核心主题与关键教学节点，写入 `courseData.json`。

---

## 阶段二 · 零磁盘高清关键帧提取 (Zero-Disk Keyframing)

1. **传统视频处理的弊端**：
   - 下载数十集 1080p 视频动辄占用 20GB–50GB 磁盘，不仅本地硬盘不堪重负，且完全无法推送到 GitHub。
2. **流媒体逐秒捕获方案**：
   - 使用 `yt-dlp` 获取远端视频的直接流地址（Direct Stream URL）；
   - 将流地址直接传入 `ffmpeg`，使用 `-ss {时间戳}` 快速寻道并只解码抓取单张 1080p 原画 PNG；
   - 耗时仅需 1–2 秒/张，磁盘零持久占用，生成的图片仅几百 KB，完美兼容 Git 仓库管理。

---

## 阶段三 · 深度图文精读与三层提炼 (Distill & Handbook)

1. **宏观图文精读讲义**：
   - 针对每一集课程，撰写由浅入深的深度讲义，包含：
     - **核心原理与底层机制**（散户/初学者视角 vs 机构/专家算法视角）；
     - **关键图解与代码/盘面抓手**（绑定高清晰度原图）；
     - **实战执行动作、关键参数与标准流程**；
     - **常见致命陷阱与避坑指南**。
2. **三层微观提炼卡片 (`cases`)**：
   - **角色一：导师原话 (`who: 老师`)**：忠实引用导师的原话精髓与核心论断；
   - **角色二：原图拆解 (`who: 老师图`)**：客观描述原图细节、K 线位置或代码执行过程；
   - **角色三：主模型归纳 (`who: 主模型`)**：将知识点归纳为可落地、可执行的检查项或规则。

---

## 阶段四 · 原生桌面应用封装与健康自检 (App & QA)

1. **原生容器封装**：
   - 采用 Apple Cocoa Swift + `WKWebView` 纯原生轻量化容器（无 Electron 几百 MB 臃肿依赖）；
   - 本地双写持久化：用户笔记即时写入 `notebook.json`，并按分钟在 `history/` 自动备份快照，杜绝丢失；
   - 系统级外链拦截：点击外链直接派发给系统默认浏览器打开。
2. **`--qa` 自动化健康检查**：
   - 内置命令行 `--qa` 参数；
   - 启动时自动注入 JS 探针，检查课程加载数量、题目数量、详情页渲染及图片加载状态；
   - 确认 `loadedImgs == imgCount` 100% 通过后打印 `QA_OK` 并优雅退出。

---

## 阶段五 · 远程同步与红点检测 (Sync & Red-Dot Alert)

1. **版本自动标记**：
   - 构建器读取本地 Git Commit SHA、提交时间戳与打包日期，生成 `version.json` 与 `version.js`。
2. **远端 GitHub 智能比对**：
   - 前端异步轮询 GitHub Commits API 与 Raw 链接；
   - 若检测到远程仓库存在更新的 Commit，界面自动点亮高对比度呼吸红点（🔴），并提供一键复制 `git pull` 更新命令。
